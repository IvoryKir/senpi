## 2026-10-27 - Preserve executable group-signal detection while ignoring inert shell text (senpi#3019)

### What changed

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: blank quoted literals, comments and inert heredoc text before scanning, while preserving executable command substitutions and shell scripts. Substitution-boundary scanning skips shell comments so their apostrophes cannot hide a following command.
- `packages/senpi-codemode/test/group-signal-notice.test.ts`: retain the quoted-text and executable-substitution cases and add the nested-comment regression.
- `packages/senpi-codemode/test/gate/allowlist.json`: register the corresponding additive detector contracts under `senpi#3019`.

### Why

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: regex-only scanning warned about inert quoted text. Quote masking must still recognize executable substitutions, including one containing an apostrophe in a shell comment.

### Why an extension could not handle it

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: the eval worker's spawner wrappers classify the command before running it; extensions cannot replace this internal detector.

### Expected merge conflict zones

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: substitution boundaries and quote-blanking helpers.
- `packages/senpi-codemode/test/group-signal-notice.test.ts`: detector table cases.
- `packages/senpi-codemode/test/gate/allowlist.json`: the `senpi#3019` contract block.
