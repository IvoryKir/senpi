## 2026-10-29 - Preserve executable group-signal detection while ignoring inert shell text (senpi#3019)

### What changed

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: blank quoted literals, comments and inert heredoc text before scanning, while preserving executable command substitutions and shell scripts. Substitution boundaries skip shell comments and distinguish case-pattern closers from the substitution's closing parenthesis.
- `packages/senpi-codemode/test/group-signal-notice.test.ts`: retain the quoted-text and executable-substitution cases and cover nested case patterns, balanced subshells, ordinary case arguments and the inert text after a substitution.
- `packages/senpi-codemode/test/gate/allowlist.json`: register the corresponding additive detector contracts under `senpi#3019`.

### Why

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: regex-only scanning warned about inert quoted text. Quote masking must still recognize executable substitutions, including shell comments and case patterns whose unmatched closing parenthesis does not end the substitution.

### Why an extension could not handle it

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: the eval worker's spawner wrappers classify the command before running it; extensions cannot replace this internal detector.

### Expected merge conflict zones

- `packages/senpi-codemode/src/kernels/js/group-signal-notice.js`: substitution boundaries and quote-blanking helpers.
- `packages/senpi-codemode/test/group-signal-notice.test.ts`: detector table cases.
- `packages/senpi-codemode/test/gate/allowlist.json`: the `senpi#3019` contract block.
