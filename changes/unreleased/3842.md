### Fixed

- A ChatGPT subscription whose access token ChatGPT reports as expired ("Your authentication token has expired. Please try refreshing it.", HTTP 401) while its saved expiry still looks valid is refreshed once and the request retried, instead of failing every turn until a new sign-in. Only a 401 whose body names the token as expired or invalid is refreshed; any other 401 (account, workspace, plan, region) is shown as it is, with no refresh and no blocked account slot. When the refresh itself is refused, the error says to sign in to ChatGPT again ([#3407](https://github.com/code-yeongyu/senpi/issues/3407)).

## 2026-10-26 - Preserve rejected-token message metadata (senpi#3842)

### What changed

- `packages/ai/src/auth/helpers.ts` and `packages/ai/src/auth/types.ts`: carry the optional rejected-token message matcher through lazy OAuth metadata so a status alone need not trigger refresh.

### Why

- `packages/ai/src/auth/helpers.ts` and `packages/ai/src/auth/types.ts`: ChatGPT also uses 401 for account, workspace, plan, and region refusals that token renewal cannot fix.

### Why an extension could not handle it

- `packages/ai/src/auth/helpers.ts` and `packages/ai/src/auth/types.ts`: the shared OAuth contract and lazy metadata are core-owned.

### Expected merge conflict zones

- LOW: OAuth metadata fields in `packages/ai/src/auth/helpers.ts` and `packages/ai/src/auth/types.ts`.

## 2026-10-26 - Pass the rejected-token message matcher to retry (senpi#3842)

### What changed

- `packages/coding-agent/src/core/model-runtime.ts`: carries the provider's optional rejected-token matcher from prepared auth into the single rejected-token retry.

### Why

- `packages/coding-agent/src/core/model-runtime.ts`: only token-specific refusals should consume a refresh or mark a pooled account as refused after re-exchange.

### Why an extension could not handle it

- `packages/coding-agent/src/core/model-runtime.ts`: request preparation owns the credential metadata consumed by the retry wrapper.

### Expected merge conflict zones

- LOW: prepared-request auth metadata and retry-attempt construction in `packages/coding-agent/src/core/model-runtime.ts`.
